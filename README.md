# langChain-langGraph-agentic-pipeline

Minimal example showing a small agentic pipeline built with LangChain and LangGraph.

## Files added
- `requirements.txt` — Python dependencies
- `langChain-langGraph-agentic-pipeline.py` — Example runner

## Setup

1. Create and activate a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate  # macOS / Linux
.venv\Scripts\activate     # Windows
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Set any required environment variables (e.g. OpenAI API key) in a `.env` file or env vars.

4. Run the example:

```bash
python langChain-langGraph-agentic-pipeline.py
```

## Notes
- This repository contains a minimal example. Pin package versions before production use.
